# 그림에 반영하는 세부 프로필

마이페이지의 **그림 속 내 모습** 또는 **프로필 편집**에서 성별 표현, 연령대, 하는 일, 외형 특징을 선택 입력합니다. 하는 일은 80자, 외형 특징은 200자까지 입력할 수 있습니다. 모두 비워 두어도 기존처럼 사용할 수 있습니다.

**내 그림에 반영하기**는 기본적으로 꺼져 있습니다. AI 전송 동의가 있어야 켤 수 있으며, 켠 상태로 저장하면 이후 새로 요청하거나 다시 그리는 개인 그림에 적용합니다. AI 전송 동의를 철회하면 이 설정도 꺼집니다. 이미 완성된 그림은 자동으로 다시 만들지 않습니다.

## 저장과 생성

- 본인의 `profiles.art_profile`과 `art_profile_enabled`에 저장합니다. 기존 계정에는 빈 정보와 꺼짐 상태가 적용됩니다. 이전 클라이언트가 새 필드를 생략해 저장하면 기존 세부 정보가 유지됩니다.
- 수동·자동 그림 생성 요청 때 선택한 정보만 `daily_artworks.profile_snapshot`으로 저장합니다. 대기 중 프로필을 편집해도 이미 요청한 그림의 기준은 바뀌지 않습니다.
- 실패한 그림을 수동 재시도하거나 다시 그리면 현재 프로필을 반영합니다. 프로필이 달라졌다면 이전 이미지 프롬프트를 다시 만들며, 기존의 날짜별 3회 제한은 유지합니다.
- 그림 모델에는 입력한 항목만 전달합니다. 선택하지 않은 성별 표현·연령대와 빈 메모는 전달하지 않습니다. 별도의 세부 프로필 정보가 없으면 기존 일기 입력 방식으로 동작합니다.
- 프로필은 인물이 등장하는 장면의 시각적 참고 자료입니다. 일기에 없는 사건·행동·감정을 만들거나 직업으로 외형과 생활을 추정하지 않도록 지시합니다. 일기 내용이 우선이며, 모든 그림에 인물을 넣도록 강제하지 않습니다.

## 공개 범위

원본 세부 프로필과 생성용 사본은 본인 계정에서만 읽을 수 있고, 공개 전시 API에는 포함하지 않습니다. 그림을 공개 전시에 올리면 반영된 외형은 그림을 통해 보일 수 있습니다.

새 필드는 하루만평이나 하루연결의 뉴스 검색 입력에 직접 전달하지 않습니다. 그림 제목·장면 요약·태그에는 일기에 명시되지 않은 세부 프로필 내용을 적지 않도록 모델에 지시합니다. 이 문장 생성 지침은 모델 출력에 대한 완전한 보증은 아닙니다.

## 검증 범위

API의 입력 제한·기존 필드 보존, AI 입력의 허용 항목·공개 응답 제외, 작업의 스냅샷 사용, 실제 PostgreSQL의 소유권·기본 꺼짐·자동/수동 생성·재시도·동의 철회를 검사합니다. 모델에 전달한 입력 검사와 실제 그림이 특정 외형을 정확히 재현하는지 확인하는 것은 구분합니다.
