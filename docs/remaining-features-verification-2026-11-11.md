## UI 수정·배포와 후속 확인

전시의 사용할 수 없는 선택을 해제하지 못하던 흐름, 프로필 화면 최초 데이터 조회가 `503`일 때의 복구, 큐레이터 버튼 문구를 수정했습니다. 변경된 운영 소스 6개는 모두 클라이언트 파일입니다. 새 배포는 21:47:23.242(KST)에 `READY`가 됐고 기존 운영 주소가 새 배포를 가리키는 것을 확인했습니다. 기존 운영 환경 변수·DB 스키마·Cron은 유지했습니다.

운영 큐레이터의 “전시할 그림 고르기” 버튼이 선택 화면으로 연결됐고 11월 10일→11일 순서의 비공개 전시 선택을 UI·DB에서 확인했습니다. 선택된 합성 그림 A의 상태만 잠시 `failed`로 바꾸자 실패 항목의 해제 버튼이 활성화됐고, UI에서 A만 해제하여 C 선택을 유지했습니다. A를 `ready`로 복원한 뒤 전체 행 지문이 원래 값과 일치했습니다. 실제 provider 실패가 아닌 통제 상태 시험입니다. 프로필 조회 `503` 복구는 실제 React 회귀 테스트 4개로 검증했으며 운영 provider 장애는 주입하지 않았습니다.
