# 자동 작업 처리·중단 복구 검증

2026-11-11(KST), [운영 사이트](https://harujogak-hihellow18.vercel.app)의 새 계정에서 합성 조각글 2개를 저장하고 기존 Supabase 1분 Cron의 실제 그림 생성·만료 선점 복구를 확인했습니다. 앱 코드·DB 스키마·환경 변수·배포는 변경하지 않았습니다. `worker_tick`이나 `/api/jobs`를 직접 호출하지 않았습니다.

## A — 지난 날짜 기록의 자연 생성

- 운영 UI로 합성 조각글을 저장한 뒤 21:22:04에 해당 글의 날짜만 11월 10일로 조정했습니다.
- 자연 Cron 21:23:00.017275: 대기 작업 생성·HTTP 전송 예약.
- 선점 21:23:02.424127 → 완료 21:23:21.556: 약 19.132초, `story`, `ready`, `attempts=1`.
- 다음 tick 21:24:00.056230: 전송 이력의 HTTP `200`·`ready`·완료를 확인했고 worker는 `idle`, 전송 대기 없음이었습니다.
- 실제 비공개 Storage 객체와 1024×1024 이미지, 날짜 상세 화면 새로고침 후 유지까지 확인했습니다.

## B — 활성 선점 보호와 오래된 선점 복구

- 두 번째 합성 조각글을 UI로 저장한 뒤 11월 9일로 이동하고, 21:24:36.761469의 한 트랜잭션에서 마감·첫 선점을 만들었습니다. `processing`, `attempts=1`이지만 GPT는 실행하지 않은 의도적 중단 상태입니다.
- 자연 Cron 21:25:00.063189: `active_processing`, 전송 대기 없음. 시도는 1회 그대로이고 새 전송은 발생하지 않았습니다.
- 21:25:17.893887에 이 작업의 `claimed_at`만 11분 전인 21:14:17.893887로 조정했습니다. 첫 선점 토큰은 유지했습니다.
- 자연 Cron 21:26:00.026583: 재전송 예약. 재선점 21:26:00.762773 → 완료 21:26:16.896, 약 16.133초입니다.
- `ready`, `attempts=2`, 선점 토큰 교체, 비공개 Storage 객체 1개를 확인했습니다.
- 다음 tick 21:27:00.053939: B 전송 이력의 HTTP `200`·`ready`·완료. worker는 `enabled=true`, `idle`, 전송 대기 없음이었습니다.

## 최종 확인과 남은 데이터

- 21:27:23에 A는 1회·B는 2회 시도로 `ready`를 유지했고, 전송은 총 2건뿐이며 모두 완료였습니다. B의 첫 선점에는 GPT를 실행하지 않아 실제 생성 이미지는 총 2장입니다.
- B 상세 새로고침 후 실제 1024×1024 이미지가 유지됐습니다. 갤러리를 다시 열어 그림 2장·조각글 2개와 썸네일/카드 이미지 4개의 정상 로드를 확인했습니다.
- 기존 계정의 조각글 5개·그림 3개와 기존 프로필 지문이 기준값과 같았습니다. 미완료·실패·사용자/날짜 중복 작업은 없고 A/B Storage 객체는 각각 1개였습니다.
- 새 계정에는 검증용 조각글 2개·동화책 그림 2개가 남습니다. 11월 11일 오늘 기록은 비어 있고 작성 가능합니다.
- 작업 처리·DB 관련 회귀 테스트 3개 파일, 32개 테스트를 실행해 통과했습니다. 이 문서 작업에서는 전체 테스트를 다시 실행하지 않았습니다.

## 검증 범위와 한계

- 실제 자정을 기다린 시험이 아니라 저장한 합성 글의 날짜를 과거로 조정했습니다. B도 실제 단말·프로세스 강제 종료가 아니라 GPT 실행 전 선점과 만료 시각을 통제한 시험입니다.
- `processing` 선점 만료 복구를 확인했습니다. 일반 `failed` 작업은 자동 재시도하지 않으며, 마지막 시도 소진·업로드 후 장애는 이번 실제 시험에 포함하지 않았습니다.
- 기존 대기 작업이 없는 열린 화면에서는 새 Cron 작업 발견에 새로고침이나 탭 복귀가 필요할 수 있습니다. 그림 개수나 예시 SVG만으로 완료를 판정하지 않고 실제 이미지 로드를 확인했습니다.
- 외부 GPT 호출·과금의 정확히 한 번 실행을 보장하는 시험은 아닙니다. 색연필·공개 전시·계정 삭제 등 다른 기능의 실제 검증 범위를 확대하지 않습니다.

증거 화면은 A 완료·B 복구 후 상세·최종 갤러리의 스크린샷으로 로컬에 보관했다. 개인 작업 환경의 경로와 스크린샷 파일은 저장소에 포함하지 않는다.
