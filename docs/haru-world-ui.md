# 하루세상과 기록 화면 개선

2026-11-26 작업. 새 기능의 이용 흐름을 다듬고, 하루만평·하루연결의 상위 메뉴를 **하루세상**으로 표시합니다. 두 기능의 이름과 기존 주소는 유지합니다.

## 지난 날짜의 작성 중인 글

갤러리 상세 화면의 입력 중인 조각과 수정 상태를 날짜별로 현재 로그인 세션의 메모리에 보관합니다. 브라우저 뒤로 가기 등으로 페이지를 벗어났다 돌아와도 이어 쓸 수 있습니다. 서버에 저장한 조각과는 별개이며, 다른 기기로 동기화하거나 브라우저를 닫은 뒤 복원하는 기능은 아닙니다.

전날·다음날과 화면 안의 다른 링크로 이동할 때 입력 중인 조각이 있으면 저장하고 이동할지 확인합니다. 저장이 완료되기 전에는 입력을 비우지 않으며, 저장에 실패하면 글과 오류 안내를 유지합니다. 응답을 받지 못한 저장 요청은 원래 조각 ID의 서버 상태를 확인하고 재시도하여 중복 추가를 방지합니다.

로그아웃·로그인 세션 변경 시 임시 입력을 비웁니다. `/api/me`가 보내는 본인의 계정 ID로 다른 탭에서의 계정 변경도 구분합니다. 임시 입력을 브라우저의 localStorage나 sessionStorage에 쓰지 않습니다. 미저장 입력이 있을 때 새로고침·탭 닫기에 브라우저의 이탈 경고를 사용합니다.

## 하루세상

- 하단 **하루세상**으로 들어가 하루만평 또는 하루연결을 선택합니다. 어느 화면에서도 같은 하단 메뉴가 선택 상태를 유지합니다.
- 완성된 결과에서는 뉴스 제목과 대표 출처를 먼저 보여주고 그림 비교·요약·해설을 이어서 표시합니다. 하루연결의 재생성은 별도 펼침 영역에 배치하며, 새 요청 전 AI 전송 정보와 생성 횟수 안내를 유지합니다.
- 날짜 입력/선택 후 **보기**를 눌러 이동합니다. 날짜를 편집하는 중에는 다른 날의 결과를 요청하지 않습니다. **오늘**은 바로 이동하며, 만평의 저장된 날짜는 접힌 목록에서 선택할 수 있습니다.
- 하루연결은 일기 날짜 기준 이전 한 달(당일 포함)의 뉴스 정책을 유지합니다. 과거 범위로 저장된 결과와 재연결할 때의 검색 범위를 구분해 표시합니다.
- 실제 저장된 그림을 누르면 크게 볼 수 있습니다. 닫기 버튼이나 Escape로 닫으면 원래 확대 버튼으로 키보드 초점을 돌립니다. 생성 전·불러오기 실패 상태는 확대할 수 없습니다.
- 만평에 재시도 가능한 시각과 날짜별 사용 횟수를 표시합니다. 대기 중인 경우와 횟수를 모두 쓴 경우를 구분합니다. 서버의 기존 재시도 제한은 변경하지 않습니다.

## 프로필

AI 전송 동의를 본문에서 읽고 설정하도록 옮겨 하단에는 저장 버튼과 저장 오류만 남깁니다. 외형 특징은 세 줄 입력창으로 보이며 200자, 하는 일은 80자 카운터를 제공합니다. 줄바꿈·제어문자는 공백으로 정리하여 기존 프로필 저장 형식과 호환합니다.

마이페이지에서는 **입력 전 / 반영 꺼짐 / 새 그림에 반영**으로 상태를 구분합니다. 선택 프로필과 AI 동의의 의미, 기존 그림을 자동으로 변경하지 않는 동작은 유지합니다.
