# 하루만평

2026-11-25에 추가한 자동 뉴스 만평 기능입니다. `/cartoon`에서 날짜별 공용 만평과 같은 날짜의 내 그림을 비교합니다. 내 그림이 없으면 기록하기 안내를 보여줍니다.

## 동작

1. Vercel Cron이 한국 시간 매일 19시대에 `/api/cartoon-jobs`를 호출합니다(`0 10 * * *`, UTC). 플랫폼 일정의 정밀도에 따라 실제 시작 시각은 달라질 수 있습니다. 19시 이후 첫 방문도 작업을 자동 요청합니다.
2. Supabase의 날짜별 행과 원자적 선점으로 한 작업만 처리합니다. OpenAI 웹 검색에서 해당 한국 날짜에 발행된 기사를 찾고, 같은 사건에 대한 서로 다른 매체의 보도 두 개 이상을 확인합니다.
3. 검색 응답의 출처 목록에 실제 등장한 허용 매체 기사 주소만 수용합니다. 날짜·원문 확인 정보·동일 이슈 여부를 검사한 근거 목록으로 대표 뉴스, 짧은 요약, 선정 이유와 만평 비유를 정합니다. 객관적인 뉴스 순위 집계는 아닙니다. 기사 발행 시각과 원문 사실은 검색 모델이 추출한 근거이며 별도의 원문 수집기는 없습니다.
4. 선정 결과를 먼저 저장하고 이미지를 생성합니다. 그림은 비공개 `news-cartoons` 버킷에 저장합니다. 인증된 API만 1시간 유효한 이미지 주소를 제공합니다.
5. 화면에는 뉴스 요약, AI 만평 해설, 선정 시각과 클릭 가능한 원문 출처가 따로 표시됩니다. 내 일기·그림·계정 정보는 뉴스 검색이나 만평 생성으로 보내지 않습니다.

## 실패와 비용 제한

- 하루 한 행과 완성 그림 한 장을 재사용하며, 준비된 날짜를 다시 생성하지 않습니다.
- 실패 후 15분, 중단된 작업의 선점 후 10분이 지나면 방문 화면에서 다시 요청할 수 있습니다. 하루 최대 3회입니다. 방문자가 없는 날의 실패를 자동 재시도하는 추가 Cron은 없습니다.
- 기사 근거가 부족하면 `unavailable`로 기록하고 그날의 만평을 만들지 않습니다. 나중에 찾은 뉴스를 과거 날짜로 발행하지 않습니다.
- 뉴스 선정 체크포인트가 있으면 이미지 재시도에서 다시 검색하지 않습니다. 동시 요청을 막지만, 외부 제공자 응답 유실 등에 따른 과금의 정확히 한 번 실행까지 보장하지는 않습니다.
- 검색·선정은 합계 최대 100초, 이미지 API는 최대 180초, Vercel 함수는 최대 300초입니다.

## 파일과 설정

| 위치 | 역할 |
| --- | --- |
| `src/app/cartoon/` | 신문 형태의 지면, 날짜 선택, 두 그림 비교, 진행 상태와 출처 |
| `src/server/cartoon-news.ts` | 웹 검색, 뉴스 근거 검증, 대표 뉴스·만평 기획 |
| `src/server/cartoons.ts` | 생성 선점, 체크포인트, 이미지 저장, 복구, 응답 구성 |
| `src/server/cartoon-handlers.ts` | 로그인·요청 출처 검사와 Cron 비밀값 검사 |
| `supabase/migrations/20261125103138_daily_editorial_cartoons.sql` | 새 테이블·RPC·비공개 버킷·접근 권한 |
| `vercel.json` | 매일 자동 발행 일정 |

기존 `OPENAI_API_KEY`, `OPENAI_TEXT_MODEL`, `OPENAI_IMAGE_MODEL`, `SUPABASE_SECRET_KEY`, `CRON_SECRET`을 사용합니다. 텍스트 모델은 Responses 웹 검색과 Structured Outputs를 지원해야 합니다. 별도 뉴스 API 키는 필요하지 않습니다. `DAILY_CARTOON_ENABLED=false`는 새 생성을 중지하며 기존 만평 조회는 유지합니다.

DB에는 이 기능의 새 마이그레이션만 먼저 적용한 뒤 앱을 배포합니다. 기존 음악 테이블을 지우는 초기 마이그레이션을 다시 실행하지 않습니다. 새 테이블은 개인 일기와 외래 키를 맺지 않으며 기존 일기·그림을 수정하지 않습니다. 브라우저 역할은 결과 일부만 읽고 생성·선점·Storage 직접 접근을 할 수 없습니다.

## API

- `GET /api/cartoons?date=YYYY-MM-DD`: 로그인 후 지면, 최근 31개 발행 날짜, 오늘 날짜, 시작 가능 여부와 시작 예정 시각을 조회합니다. 미래 날짜는 거절합니다.
- `POST /api/cartoons`, 본문 `{}`: 로그인과 동일 출처를 확인하고 오늘의 작업만 요청합니다. 응답 이후 `after()`에서 처리하며 진행 상태는 조회 API로 확인합니다.
- `GET|POST /api/cartoon-jobs`: `Authorization: Bearer CRON_SECRET`이 필요합니다. 환경의 기존 Cron 비밀값은 로그나 응답에 포함하지 않습니다.

검증은 뉴스 출처·날짜 검증, DB 권한·동시 요청·시도 제한, API 인증, 생성 작업의 실패 복구를 포함합니다. 모의 API와 PGlite 검증은 실제 뉴스 검색 및 이미지 생성 검증과 구분합니다.
